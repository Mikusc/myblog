# 宁诺校园 3D 导览

公开页面：`https://www.mikusc.top/campus/`。项目页和工具页提供入口，导览页可返回博客。

`source/campus/` 是校园项目 `campus-site` 导出的完整静态版本，包含同源的界面、Three.js 和模型文件；不依赖原有 Sites 地址、第三方 iframe 或服务端运行时。Hexo 通过 `_config.yml` 中的 `skip_render: campus/**` 原样复制，沿用当前 GitHub → Azure Static Web Apps 发布流程。

## 更新导览

1. 在校园项目的 `campus-site` 目录运行 `npm run build:blog`。
2. 将 `dist-blog/` 的完整内容同步到本仓库 `source/campus/`，移除被新版替代的旧哈希资源。不要手改编译后的 JavaScript。
3. 运行本仓库 `npm run build`，确认 `public/campus/index.html` 及其引用资源齐全。检查 `/campus/`、视角切换、返回博客、资料说明以及博客中的两个入口。
4. 按博客发布流程提交并推送，等待 Azure 工作流成功，再检查公开地址与模型清单。

当前模型为 `unnc-campus-satellite-roads.glb`（`2026-09-22 satellite road refinement 1`）。导览保留对数深度缓冲以减少屋顶、水面、操场和绿地的闪烁。模型按哈希命名并分块传输；支持浏览器优先下载约 16.5 MB 的 gzip 分块（比原始 66.7 MB 减少 75.2%），解压后逐字节一致并校验 SHA-256。旧浏览器保留原始分块回退。2026-09-22 道路校核模型 SHA-256：`5435cd146ef591d6bdf84551e691d4e6f219088372fe0696ebcda0efbcee847e`。

`source/campus/sources.html` 保留参考资料、估建限制和 OpenStreetMap/ODbL 来源说明；更新时必须一起保留。

## 2026-09-22 建筑第三轮细化

当前模型为 `unnc-campus-refined-3.glb`。根据校方图书馆航拍、临河实拍及2020年相册，补临河四层开敞露台、连续楼板、扶栏、三组屋顶机电阵列；根据会议场地实拍、校园全景及校方年报，细化Dearing浅石材基座窄窗、四层幕墙、三杆雨棚、屋顶光伏及设备。照片日期和构件尺寸不确定性在资料页标注，会议照片未新增托管。

178个非目标Blender网格摘要一致。图书馆凹入射线检查与闭合楼板检查通过，楼板在转角做实体合并以消除共面重叠。网页继续保留按需渲染、规划对象显隐、建筑点选、手机取景及对数深度缓冲。GLB、无损解压和网页构建的验证结果随此次发布记录。

## 2026-09-22 导览优化

- 静止时停止持续绘制；交互、阻尼、镜头过渡和自动环绕按需刷新，后台标签页暂停。
- 手机竖屏采用更俯视的全景构图，横竖屏和全屏变化后重新取景；底部导览支持收起。建筑面板与模型并排／上下排布。
- 现状／建成愿景开关控制两处规划建筑及配套幕墙、连廊、树木和庭院；不表示实时施工状态，不恢复历史地块细节。
- 15 个主要建筑或建筑组可以直接点选，也可搜索名称。面板包含入口方向和来源说明，共 16 张实景照片／规划效果图；尚缺独立照片的建筑明确注明并链接校园全景。
- `source/staticwebapp.config.json` 只调整 `/campus/` 资源缓存：模型清单与入口重验证，哈希模型／脚本长期缓存，照片缓存一天。配置包含 `.gz` MIME 映射；线上 Azure 将这些文件作为预压缩二进制资源，以 `application/octet-stream` 和 `Content-Encoding: gzip` 响应。浏览器会自动解压，客户端兼容这一行为。

源项目增加 `npm run model:compress` 与 `npm run test:campus`。每次更新先验证原模型哈希、gzip 还原、GLTF 解析、规划对象覆盖和视口取景，再构建并检查静态导出。照片按需加载，保留作者、拍摄日期及许可链接。测试不等同于真实手机耗电基准。
